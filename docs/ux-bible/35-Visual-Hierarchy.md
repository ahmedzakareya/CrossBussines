# 35 — Visual Hierarchy

Order of attention: page identity/context → state/critical alert → primary action → current task/content → supporting detail → metadata. Apply the typography, spacing, color, radius, elevation and token rules from `../design-system/`.

Use one H1, concise section headings, sentence-case labels, tabular figures for numeric comparison, and muted text only for genuinely secondary information. CrossBusiness Blue marks platform identity, links, focus and primary actions. Financial green carries accounting meaning only. Status always uses text/icon in addition to color.

Use whitespace and borders before shadow; maximum two card layers; avoid cards around every subsection. A page header and card header must not repeat the same title. Dense screens reduce spacing deliberately, not font legibility or focus visibility. RTL uses logical alignment; dark mode preserves hierarchy rather than mechanically inverting values.
