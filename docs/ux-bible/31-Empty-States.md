# 31 — Empty States

Empty means a successful request returned no applicable content. It is not loading, error, denied or unavailable.

Use Metronic card/table empty anatomy: restrained KeenIcon or illustration where helpful, factual title, one-sentence explanation, and at most one primary next action plus a reset-filter link. Types: first-use, no results, filter-constrained, completed/cleared queue, and not-yet-applicable. Name the current scope when ambiguity exists.

Do not celebrate absence in serious operational/financial contexts, imply creation permission the user lacks, or use a blank card. Keyboard focus stays in the surrounding flow. Screen readers receive a concise status. Mobile keeps the action visible; RTL mirrors composition; dark mode uses tokens. Examples: “No tasks match these filters — Clear filters”; “No transactions in this period — Change period.”
