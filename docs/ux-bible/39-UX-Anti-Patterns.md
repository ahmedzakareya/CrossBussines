# 39 — UX Anti-Patterns

- Replacing or wrapping a Metronic primitive without a documented capability gap.
- A second token/component framework or view-local raw color/spacing system.
- Legacy financial green used for platform chrome or primary action.
- Multiple primary page actions, nested cards beyond two, nested dialogs.
- Modal used for a long workflow; drawer used to hide essential navigation.
- Blank, spinner-only, or generic-error screens; empty used for denied/unavailable.
- Authorization implemented only by hiding/disabling client controls.
- Table rows that ambiguously select and navigate; icon-only action clusters.
- Hover-only action, drag-only Kanban/calendar, keyboard trap, lost focus after close.
- Placeholder-only labels, validation that clears input, silent autosave for consequential data.
- Dashboard as metric collage; chart without scope/provenance/text alternative.
- Desktop table squeezed onto mobile; navigation or content removed at a breakpoint.
- Physical left/right styling that breaks RTL; forced RTL for codes/amounts.
- Infinite loading, full-page overlay for local refresh, toast storms.
- Extending legacy Comm/Chat as the new Communication architecture.
- Rebuilding existing Tasks or Calendar rather than evolving them.
- Claiming architecture/planned work is implemented or a disk artifact is verified/activated.

Existing occurrences are migration evidence, not permission to reproduce them.
