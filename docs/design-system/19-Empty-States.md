# 19 — Empty States

Empty is a valid successful response with no records. It is distinct from loading, unavailable, denied, filtered-to-zero, partial and error.

## Anatomy

Optional restrained icon, specific title, one-sentence explanation, and at most one primary plus one secondary action. Actions appear only when authorized.

Examples: “No invoices yet” with Create invoice; “No results match these filters” with Clear filters; “Communication is not activated” as unavailable with no misleading create action.

Do not use celebratory emptiness for operational queues unless zero genuinely means healthy. Tables render the state across all columns; cards use a centered state with stable minimum height to avoid layout jump.
