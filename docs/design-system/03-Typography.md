# 03 — Typography

## Families

- Arabic: **Cairo**, falling back to system Arabic sans-serif.
- Latin: **Inter**, falling back to system UI sans-serif.
- Numeric and code: inherited UI font with `font-variant-numeric: tabular-nums`; monospace only for identifiers, SQL/code, hashes, and machine payloads.

## Scale

| Role | Size/line | Weight |
|---|---|---|
| Display | 32/40 | 700 |
| Page title | 24/32 | 700 |
| Section title | 18/26 | 600 |
| Card title | 16/24 | 600 |
| Body | 14/22 | 400 |
| Compact body/table | 13/20 | 400/500 |
| Label | 13/18 | 600 |
| Caption/meta | 12/18 | 400/500 |

Use no more than three weights on one screen. Sentence case is default. Uppercase is limited to short Latin metadata; do not uppercase Arabic. Amounts, quantities, dates, and identifiers use tabular numerals. Truncation requires a tooltip or accessible full-value mechanism.
