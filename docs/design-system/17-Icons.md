# 17 — Icons

Keen Icons (`ki-outline`, with solid only for selected/emphasis) are canonical because they ship with Metronic and dominate current views.

## Rules

- 16–20 px inline, 20–24 px controls, 32–48 px state illustrations.
- Icons accompanying text are decorative unless they add distinct meaning.
- Icon-only buttons require an accessible name and tooltip.
- Use one icon for one meaning across modules: plus/create, pencil/edit, trash/delete, eye/view, filter, download/export, calendar, clock, warning.
- Directional icons mirror in RTL when they mean back/forward or start/end; physical concepts do not.
- Do not mix emoji, Font Awesome, inline SVG and Keen Icons on the same product surface without an approved exception.
- Status is icon + label + color, never color/icon alone.
