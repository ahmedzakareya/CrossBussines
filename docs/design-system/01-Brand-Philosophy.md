# 01 — Brand Philosophy

CrossBusiness is an enterprise operating system: calm, exact, bilingual, and accountable. Its visual character should communicate control without bureaucracy and density without clutter.

## Identity

- **CrossBusiness Blue** represents platform navigation, primary actions, links, focus, selection, and shared products.
- **Financial Green** represents accounting/finance facts: profit, favorable variance, balanced books, financial charts, and accounting report content. It must not color global navigation or generic primary buttons.
- Warm orange is attention, not a second brand primary. Red is destructive/critical, green is success, amber is warning, blue is information.
- Product chrome is neutral and blue-biased. Domain content may use semantic palettes.

## Product voice

Use direct nouns and verbs: “Create invoice”, “Approve”, “Retry dispatch”. Avoid decorative copy, unexplained acronyms, and generic errors. State what happened, why, and what the user can do next. Arabic is first-class rather than a translated afterthought.

## Evolution from the current product

Retain Metronic’s proven app shell, typography utilities, controls, modal behavior, tables, plugins, and Keen Icons. Elevate the scoped Workspace/Reporting Blue vocabulary into the future platform token source. Migrate legacy green chrome progressively; do not flip 327 screens globally.

## Marks and naming

- Product name: **CrossBusiness Platform**; short shell label: **CrossBusiness**.
- Module names remain business nouns: Accounting, Inventory, CRM, Projects, People, Tasks, Calendar.
- Use the existing compact square mark pattern from `.cbw-brand-mark` until an approved logo asset exists.
- Never use color alone to distinguish modules or status.
